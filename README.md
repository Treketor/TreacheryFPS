# Treachery

Treachery is a retro horror FPS prototype built solo in Unity and C#. It is a wave-based survival shooter with a deliberately PS1-era visual style.

## Features
- Three enemies on Unity NavMesh: zombies that spread out and circle you, a Grave Digger that fights up close and throws dirt from range, and a Wretch that stalks, retreats, screeches and charges.
- Four guns: pistol, pump shotgun, AK-47 and dual Uzis.
- Endless waves that grow and speed up, with souls dropped by enemies.
- A custom PS1-style shader with vertex snapping and vertex-colour tinting. Affine texture mapping is supported but currently switched off.
- First-person and enemy animation driven by the Unity Animator, with blend trees for enemy movement.

## Status
Playable in the Unity editor, with no downloadable build yet. Sound, the weapon upgrade machine (being reconnected after a weapon system rebuild), designed waves and an ending are still to come.

## Tech
Unity 6 (URP), C#, Blender for models and animation, and a custom shader.
