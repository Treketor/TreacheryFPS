# Treachery

Treachery is a retro horror FPS built solo in Unity and C#. It is a wave-based survival shooter with arcade-style progression and a deliberately PS1-era visual style.

## Features
- Enemy AI built with state machines and Unity NavMesh, with several enemy types and distinct behaviours.
- Weapon and combat systems with multiple weapons and a soul-collection progression and upgrade loop.
- A custom PS1-style rendering pipeline: vertex snapping, affine texture mapping and vertex-colour tinting.
- First-person and enemy animation driven by Unity Animator and blend trees.
- Profiled and optimised for consistent real-time performance, with integrated audio and UI.

## Tech
Unity 6 (URP), C#, Blender for models and animation, and custom shaders.
